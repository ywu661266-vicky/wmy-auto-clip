# 动效库配置说明（effects.json）

`scripts/effects.py` 只认一个配置：`effects.json`。改这一份文件，就能让 WorkBuddy 帮你生成「代码卡点动效」。
下面左边是字段，右边是它干什么。**时间码一律写「视频里的秒数」**（从 0 开始）。

动效的「手感」来自缓动曲线与入场预设库 `fx_engine.py`（移植自开源项目 adunext/adu-motion-video，MIT 许可）：
弹性 `spring`、回弹 `back`、指数 `expo`、进出 `inout` 等曲线，以及 `up`(上滑入) / `pop`(弹入) / `slam`(砸入) / `zoom`(缩放入) 等入场预设，全部按阿杜原版思路用纯 Python 复刻，逐帧用 Pillow 绘制。

```json
{
  "title": {                       // ① 开场标题卡（视频开头逐词弹入，几秒后淡出）
    "start": 0.0,                  //   出现时间（秒）
    "end": 3.8,                    //   消失时间（秒）
    "line1": "我的复盘",           //   主标题（大字，按词组逐个弹入，移植自阿杜 wordsAt 手法）
    "line2": "本周复盘 ｜ 我的频道" //   副标题（小字，下面有强调色下划线）
  },
  "chapters": [                    // ② 章节卡（话题一转就弹出来，带序号）
    { "start": 17.0, "num": "①", "text": "把别人的经验，做成自己的 Skill" },
    { "start": 66.8, "num": "②", "text": "年轻人，不会被 AI 淘汰" },
    { "start": 83.0, "num": "③", "text": "开源，让学习的门槛消失" }
  ],
  "keywords": [                    // ③ 关键词胶囊（说到关键词时左右轮换弹出）
    { "start": 0.0,  "text": "AI",     "side": "left"  },  // side: left=靠左, right=靠右
    { "start": 17.9, "text": "Skill",  "side": "right" },
    { "start": 83.0, "text": "开源",   "side": "right" }
  ],
  "numbers": [                     // ④ 数字卡（大数字滚动到位 + 底部进度条 + 副标题）
    {
      "start": 20.0,               //   出现时间（秒）
      "end": 24.5,                 //   消失时间（秒）
      "at": 20.4,                  //   数字开始滚动的时刻
      "dur": 1.8,                  //   滚动持续秒数（越大越有"数出来"的感觉）
      "from": 0,                   //   起始值（一般 0）
      "value": 1840000,            //   目标值
      "fmt": "wan",                //   数字格式：wan=万(1840000→"184万") / pct=百分比(92→"92%") / raw=原样
      "unit": "行代码",            //   单位（为空字符串则不显示），跟在数字右侧
      "label": "这份开源模板的总规模", // 卡片内顶部小标签
      "sub": "几十组动效模板，全部可改" // 卡片内补充说明（在进度条上方）
    }
  ],
  "steps": [                       // ⑤ 步骤卡（时间线逐段点亮，横屏横向 / 竖屏自动转纵向）
    {
      "start": 70.0,               //   出现时间（秒）
      "end": 76.0,                 //   消失时间（秒）
      "steps": [                   //   每一步：[文字, 弹出的时刻(秒)]
        ["写好故事旁白", 70.4],
        ["拆成三个分镜", 71.6],
        ["逐镜生成画面", 72.8],
        ["拼片加字幕", 74.0]
      ]
    }
  ],
  "cta": {                         // ⑥ 结尾 CTA 卡（半透明，人还在说话脸能透出来）
    "start": 196.0,                //   出现时间（秒）
    "end": 214.0,                  //   消失时间（秒）
    "lines": [                     //   从上到下的几行字（最后一行默认强调色）
      "这门课出品了，",
      "你愿意来听吗？",
      "评论区留言，一起探讨 ↓"
    ],
    "tag": "关注我"                //   底部小标签
  },
  "style": {                       // ⑦ 配色（想换风格就改这里，RGB 0-255）
    "accent":       [255, 92, 138],  // 强调色（标题下划线 / 胶囊 / 进度条 / 数字）
    "accent_light": [255, 143, 179], // 浅强调色（章节序号 / CTA 第二行）
    "ink":          [18, 18, 26],    // 暗底（卡片背景）
    "white":        [255, 255, 255], // 白字
    "grey":         [225, 225, 235]  // 灰字（副标题 / 章节正文 / 进度说明）
  }
}
```

## 使用步骤（发给 WorkBuddy 的话术）

> 运行 effects.py，视频用【你的片.mp4】，配置用【effects.json】，输出【成片.mp4】。
> （想要背景音乐就说）再加背景音乐【bgm.wav】，我说话时自动压低。

## 学员最常改的 6 处

| 想改什么 | 改哪个字段 | 例子 |
|---|---|---|
| 换标题 | `title.line1` / `title.line2` | `"line1": "我的复盘周报"` |
| 换章节 | `chapters` 整个数组 | 删几行、改 `text` 和 `start` |
| 换关键词 | `keywords` 整个数组 | `"text": "DeepSeek"`, `"side": "right"` |
| 加「数字冲击」卡 | `numbers` 数组 | 见上方字段表，`fmt` 用 `wan` 最出效果 |
| 加「流程步骤」卡 | `steps` 数组 | 见上方字段表，竖屏会自动排成纵向时间线 |
| 换结尾话术 / 配色 | `cta.lines` `cta.tag` / `style.accent` | 玫红改蓝：`[92, 138, 255]` |

## 时间码怎么拿

跑「长剪短」那条链路时，WorkBuddy 会同时给你带时间码的文字稿（每行前面 `[00:17.9 --> ...]`）。
把你想卡点的那句的**起点秒数**填到 `start` 即可。关键词胶囊默认停留 2.6 秒、章节卡 3.2 秒、标题/CTA 按你给的起止。

## ⚠️ 大卡别撞时间（自动预警）

标题卡、数字卡、步骤卡、CTA 卡都占画面中央区域。脚本会检查它们的时间窗：
**若两段大卡时间重叠，运行时会打印 `[warn] … 互相遮挡` 提示**，此时把其中一张的 `start`/`end` 错开即可。
（小元素——章节卡、关键词胶囊——贴在顶部/两侧，和中央大卡不冲突，可同时出现。）

## 适配场景 / 不适合

- **适合**：口播、访谈、课程片段、复盘——凡是「人说话 + 有清晰章节/金句/数据」的竖屏或横屏视频。
- **不适合**：纯风景空镜、无配音画面、需要逐字精准字幕对齐的正式字幕片（那种用 enhance.py 的硬字幕更稳）。
