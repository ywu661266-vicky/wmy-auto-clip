## 〇、先回答三个问题

**Q1：工具直接给大家用，那这节课干嘛？**
课不是教"怎么点按钮"，是教**怎么当导演**。AI 能干的是机械活（听、剪、拼、拉齐、烧字），干不了的是：**选哪段、什么顺序、节奏怎么卡、审美怎么定**。学员带走的是一套"把活分清楚"的方法：什么交给 AI、什么自己拍板。这恰恰是 3 小时的内容——两个场景各练一遍，人人手里出片。

**Q2：发给学员的到底是什么？**
一个 **ZIP 绿色包**（她解压双击即用，见第四节）+ 一个 **练习素材包 ZIP**（现场剪这个出成品）。不用等平台上架（审核要 7 天，来不及），不用 U 盘，不用单独发 bat（会被当病毒拦）。

**Q3：3 小时怎么排满？**
两个场景各一轮实操（长剪短 45′ + 散拼长 60′，含进阶），加演示、原理、安装、复盘，正好 180 分钟。硬指标：**下课 80% 学员拿到两条自己的成片**（一条剪短的、一条拼出来的）。

## 一、自动剪辑是啥（讲师话术，照着说就行）

"大家剪视频，最累的不是想创意，是重复体力活。今天这套工具，**免费、在你自己电脑上跑、不花一分钱**，专门替你干两种体力活：

**第一种，长的剪成短的。** 一段啰嗦的口播/课程录像，AI 自动：把话变成文字稿 → 剪掉中间的静音空白 → （需要的话）烧上字幕。你只管扫一眼改错字。

**第二种，散的拼成整的。** 你手机里攒了一堆素材：横的竖的、60 帧的 30 帧的、分辨率乱七八糟、音量有大有小。以前在剪映里得一段段手动统一，现在 AI 一次拉齐：统一规格 → 按你定的顺序拼 → 加转场 → 配乐 → 烧字幕。**顺序你说了算——文件名改成 01_ 02_ 03_ 就行。**

记住一句话：**AI 干重复体力活，人定顺序、改错字、把审美关。**"

## 二、三条 SOP（标准作业流程）

### 场景 A：长剪短

```
你的长视频（口播/录屏/课程）
        │
   ① 听：AI 转写 → 文字稿.srt    │ 人：扫一眼改同音错字
        │
   ② 剪：AI 剪静音 → 粗剪.mp4    │ 人：顺的片子不删（安全）
        │
   ③ 写：烧字幕（可选）          │ ⚠️ OCR 检出原片有字幕会自动拦
        │
      干净成片 ✅
```

### 场景 B：散拼长

```
一堆零散素材（文件夹/zip，横竖混、分辨率乱）
        │
   ① 读：解压/列出所有片段（按文件名排序）
        │
   ② 齐：统一化（分辨率/帧率/横竖/音量拉向一致）
        │      竖屏内容 → 放大模糊背景居中，不裁不变形
   ③ 拼：按 01_ 02_ 03_ 顺序拼接（可加 0.5s 叠化）
        │
   ④ 配：可选 BGM（压低+淡入淡出）
        │
   ⑤ 报：出一份《剪辑报告》——AI 对每段做了什么
        │
      合辑成片 ✅
```

### 场景 C：选段拼片（"挑有用的再拼"——新课重点）

```
一堆零散素材（不知道哪段有用）
        │
   ① 听全部：AI 转写每一段 → 《素材文字稿》（每段带时间戳）
        │
   ② 人/AI 挑段：看文字稿填《选段单》
        │      文件名 + 起始-结束 + 备注，顺序=成片顺序
        │      （也可以把文字稿整份发给 WorkBuddy/豆包 按主题挑）
        │
   ③ 执行：AI 按选段单剪时段 → 统一化 → 拼接 → BGM
        │
      你的成片 ✅  ← 叙事来自你，不是机器
```

**为什么这样设计（讲师必须讲清的道理）**：
- "哪段有用"是**语义判断**，业界所有开源 AI 剪辑工具（AutoClip、ai-highlight-clip、clipit）都是"Whisper 转写 → 大模型挑段 → ffmpeg 剪"三段式；
- 本方案零积分落地点：**whisper 出文字稿免费，WorkBuddy/豆包当"挑段大脑"（学员本来就在用，不额外花钱）**；
- 学员当导演，AI 当执行——这正是"AI 时代人的价值"的现场教学。

### ⭐ 拼接时的段级智能字幕（四个真实现场行为，课上演给学员看）

拼接类模式（B/C）对**每一段独立判断**，实测四种行为：

| 段的情况 | 行为 | 现象 |
|---|---|---|
| 没人声（纯音乐/空镜） | 不烧 | 背景歌被滤掉，AI 不瞎编歌词 |
| 画面有文字（自带字幕/水印字幕/屏显） | ⛔ 保守不烧 | 报告列出检出的文字（如"天工AI"水印） |
| 有人声 + 画面干净 | 烧单层字幕 | 只有这段有字幕 |
| 确认是背景屏文字 | `--force-sub` 强烧 | 学员自己判断后才强烧 |

字幕在**拼接前逐段烧录**，时间轴天然对齐。

## 三、能力边界 + 和剪映的诚实对比

| 事 | 剪映（专业版） | 本工具 |
|---|---|---|
| 自动字幕 | 有，要手动点，部分要会员 | 一行命令/一句话 |
| 剪静音 | 有（智能剪口播） | 有 |
| **多素材统一规格** | **手动一段段调** | **自动全拉齐** |
| 批量处理 | 难 | 天然支持（文件夹/zip） |
| 转场/BGM | 手动拖 | 一条参数 |
| 费用 | 部分功能会员/付费 | 全免费 |
| 隐私 | 素材上云 | **全本地** |
| 精细手动调整 | 强 | 弱（只干粗活） |

**课上要讲的原话**："单条视频要精修、要手动抠细节——用剪映，它更顺手。**批量、合辑、要嵌入自己的工作流、不想把素材传上网——用这套。** 两个都学，不冲突。"

**AI 做不到的（别夸大）**：替你决定"哪段好看""故事怎么讲";花式动效（花字/粒子/动态包装）要走另一条路（见 SPEC §五，作加餐演示）。

## 四、分发清单（你发啥 / 学员装啥）

### 你发两个 ZIP（微信直接发）

**1.《AI自动剪辑_技能包_v7.zip》（约 3MB）**
```
wmy-auto-clip/
├── SKILL.md              技能说明书（AI 读）
├── install.py            一键安装器（AI 跑这一条就装完）
├── scripts/              三个引擎脚本
├── assets/               自带无版权 BGM
└── references/           学员手册、配置说明、降噪调参笔记
```
学员操作（推荐 WorkBuddy 路线）：把 ZIP 拖进对话框 → 说「帮我装这个技能」→ AI 跑 `install.py --zip`，装完自动体检并打印该用哪条命令 → 以后一句话就能剪。

**2.《AI自动剪辑_学员练习素材包_v1.zip》（约 10MB）**
四段"故意不规范"的素材（怪分辨率横屏/竖屏/标准横屏/有人声口播）+ BGM + 学员任务单。现场剪这个出成品，**下节课换素材包就能开新题，工具不用动**。

### 为什么不单独发 bat / 不等平台上架
- 单独发 bat：微信常当病毒拦、双击弹 SmartScreen 警告，学员不敢点。**装进 zip 里当"软件包"发，最顺。**
- 技能上架公共平台要审核 7 天，来不及。**本地装即用**：把技能包给学员，让 WorkBuddy 代装；或在 WorkBuddy 里说"安装这个技能"。
- 走 WorkBuddy 的学员：装 `wmy-auto-clip` 技能后，一句话就能剪（见第七节提示词），比 bat 更省事。**两条路并存，学员自选。**

### 学员需要准备的
- Windows 10/11 电脑；有 WorkBuddy（自带 Python+ffmpeg，零额外安装）或自己装过 Python。
- 首次跑联网一次（免费下语音模型约 480MB，走国内镜像，不花积分）。
- **不需要**会命令行、不需要买任何软件、不花一分钱。

## 五、讲师手册（3 小时逐段）

> 硬指标：下课 80% 学员拿到**两条**成片——一条"剪短的"、一条"自己挑段拼出来的"。

| 时段 | 内容 | 老师动作 | 学员动作 |
|---|---|---|---|
| 0:00–0:20 | 概念 + 三场景对比演示 | 投屏放三个"前/后"：①长片剪短 ②乱素材拼合辑 ③**选段拼片**（重点演示：文字稿→挑段→成片） | 看、提问 |
| 0:20–0:35 | 原理与三条 SOP | 画三张流程图；重点讲"挑段是人/AI 的活，AI 不猜"；段级字幕四行为 | 记两句口诀 |
| 0:35–0:50 | 安装绿色包 | 投屏带装①；巡场帮卡住的（重点：别跳过①） | 双击①装环境 |
| 0:50–1:25 | **场景 A 实操：长剪短** | 发话术/巡场；演示"原片有字幕别烧" | 用自己的口播/课程视频，跑出成片 |
| 1:25–1:55 | **场景 C 实操：选段拼片（新课核心）** | 发练习素材包；带大家对素材跑 `--draft` 出文字稿 → 示范填选段单 → 拼片；演示"把文字稿发给 WorkBuddy/豆包 帮你挑" | 看文字稿、填自己的选段单、拿到叙事合辑 |
| 1:55–2:20 | **场景 B 实操：散拼长 + 段级字幕智能** | 让大家把素材包直接整包拼一遍；现场展示四种段级字幕行为（无人声不烧/有文字拦截/干净才烧/force强烧）——**这就是她批评的"双字幕"问题的根治现场** | 整包拼一次；观察报告里每段的字幕决策 |
| 2:20–2:40 | 进阶 + 花式加餐 | 演示 `--transition fade`、`--bgm`、重命名换序；**演示选段单标 `[字幕]` 只给采访段加字**、降噪链（嘈杂现场素材前后对比）；花式（动效卡库）演示一个 | 烧字幕、改顺序重跑、围观花式 |
| 2:40–2:50 | 批量思维 + 坑复盘 | 讲"一次处理 50 条"的思路；复盘今天的坑（双字幕/歌词乱入/av版本/没人声） | 对照自己踩的坑 |
| 2:50–3:00 | 展示收尾 | 每人亮成片；点题"AI 拿不走的是你的审美和判断——挑段的就是你" | 展示、拍照 |

**现场演示素材建议**：提前用练习素材包跑一遍选段全流程（约 2 分钟），课堂上直接放"文字稿 → 选段单 → 成片"，这是全场最有说服性的三连。

## 七、给 AI 的执行提示词

### A. WorkBuddy 版（已实测环境，主推）

**长剪短：**
> "用 wmy-auto-clip 技能，把 `D:/素材/我的视频.mp4` 自动剪辑：本地转写、剪静音、如果原片没有字幕就加上字幕。跑完告诉我成片路径，并抽一帧确认画面正常、没有双字幕。"

**散拼长：**
> "用 wmy-auto-clip 技能处理 `D:/素材/活动素材/`（或 zip）：读出所有片段，统一规格，按文件名顺序拼成合辑，加叠化转场，配 `BGM.mp3`，有人声的段落烧上字幕（先确认素材原本没字幕）。跑完给我成片路径和剪辑报告，并抽帧确认字幕是单层。"

**选段拼片（新课重点）：**
> "用 wmy-auto-clip 技能，先对 `D:/素材/活动素材/` 跑 `--draft` 出文字稿，再按我挑的段落用 `--picks` 拼成合辑。跑完给我成片路径和选段报告，并抽帧确认每段都拼进去了。"

> 技能名必须写准：**`wmy-auto-clip`**（显示名「AI自动剪辑」）。写成 `ai-auto-clip` AI 会找不到技能。

### B. 豆包工作版（同款逻辑）

> "请完成 AI 自动剪辑：① 确保环境有 ffmpeg 和 Python，执行 `pip install 'faster-whisper==1.2.1' 'av<19'`；② 对 `路径/视频或素材文件夹` 运行 autoclip 逻辑（长剪短：转写+剪静音；散拼长：统一化+按文件名顺序拼接+可选转场/BGM/字幕）；③ 原片/素材有字幕则不要烧；④ 回报输出文件路径。"

⚠️ 说明：豆包工作的执行沙箱我没实测过预装环境，首次跑若报缺环境，就让它先装（第①步已含）。**WorkBuddy 是实测过的，主推 A。**

## 八、讲师备注：现场事故与救场

| 事故 | 现场现象 | 救场话术 |
|---|---|---|
| 双字幕 | 画面两层字 | "这就是今天最重要的坑——原片有字幕千万别烧。大家记住这句口诀。"（可故意用带字幕素材演示一次事故现场） |
| 没人声 | 提示"没转写出文字" | "AI 不瞎编，没人声它就直说。想有字幕换有人声的素材。" |
| 模型下载慢 | ①卡住不动 | "首次要下 480MB 模型，国内镜像也看网速。卡住超过 5 分钟就举手，先用讲师跑好的成片讲课，别干等。" |
| 装环境崩 | pip 报 av 错误 | 安装命令已锁版本 `av<19`，正常不会犯；若犯，把 pip 那行原样重跑一次 |
| 素材里有坏文件 | ffmpeg 报 `Invalid NAL unit size` / `moov atom not found` | **已自动处理**：坏的那段会被跳过、其余照常拼完，失败段写进剪辑报告。让学员重新下载那一段素材即可，不用重跑整批 |
| 控制台一屏乱码 | 老版本脚本在 Windows GBK 终端打印符号 | **已修**（输出切 UTF-8 + 符号换成纯中文标记）。现场直接重装一次技能包 |
| 顺序不满意 | 合辑顺序不对 | "文件名改一下 01_ 02_ 03_，重拖一次——顺序永远你说了算。" |
