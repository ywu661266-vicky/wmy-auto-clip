# 降噪链调参笔记（2026-10-29 频谱实测）

现场活动素材的人声普遍带三层脏东西：

1. **低频隆隆**（空调、风扇、无人机嗡声、脚步）——0–500Hz 一条持续不断的能量带
2. **中频环境噪声云**（人群嘈杂、键盘、远处说话）——2–4kHz 铺满整片
3. **高频嘶声/啸叫**——10kHz 以上

肉眼听只觉得"吵"，但看不出来脏在哪一层。三组参数跑同一段，出一张 `showspectrumpic`（`scale=log`）对比图，一眼就能看出哪层被削掉了。

## 三组参数对比

| 组 | 滤镜链 | 频谱结论 |
|---|---|---|
| A（旧默认，偏弱） | `highpass=f=120,afftdn=nf=-30:tn=1,lowpass=f=14000,agate=threshold=0.005:ratio=3:attack=40:release=300` | 低频底噪明显变暗，但 2–4kHz 仍铺着大片红色噪声云 |
| B（中间） | `highpass=f=150,afftdn=nf=-35:tn=1:nr=24,lowpass=f=12000,agate=threshold=0.008:ratio=4:attack=30:release=250` | 低频基本压掉，2–4kHz 噪声云仍明显 |
| **C（当前默认）** | `highpass=f=180,afftdn=nf=-38:tn=1:nr=30,lowpass=f=11000,agate=threshold=0.01:ratio=5:attack=25:release=200,afftdn=nf=-30:tn=1:nr=18` | 低频底噪几乎归零、中频噪声云基本压掉，0–4kHz 人声谐波竖条完整保留 |

## 结论

- **真正起作用的是 `nr`（降噪量），不是 `nf`。** `nf` 是噪声基底估计，`nf` 拉到 -38 已经接近极限，再拉只会连人声一起削；`nr` 从默认 12 提到 24–30 才是压掉噪声云的主力。
- **第二道轻降噪（`afftdn=nf=-30:nr=18`）有效果**，收掉第一道留下的残留噪底。
- `highpass` 从 120 抬到 180 不伤人声（人声基频 85–180Hz，但 180Hz 以上的主要能量不受影响），低频隆隆掉得更干净。
- `lowpass` 收到 11000 会损失一点"空气感"，换彻底干净。采访口播可用，风景/氛围类素材要慎用。
- `agate` 的 threshold 从 0.003 抬到 0.01、attack 收到 25ms：静音段彻底闭嘴，但人声字头（辅音）不受影响。

## 复现命令

```bash
# 降噪前后各出一张频谱图对比
ffmpeg -y -i 原始段.mp4 -lavfi "showspectrumpic=s=1100x520:mode=combined:scale=log" _spec_raw.jpg
ffmpeg -y -i 原始段.mp4 -af "<上面的C组链>" -c:a aac -b:a 160k _t.m4a
ffmpeg -y -i _t.m4a -lavfi "showspectrumpic=s=1100x520:mode=combined:scale=log" _spec_clean.jpg
```

## 别再往狠里加

再削人声就发闷、带"电音"了。真嫌不够干净，优先加 `nr`，其次是把人声单独抽出来做处理再混回去，别在主链上硬压。
