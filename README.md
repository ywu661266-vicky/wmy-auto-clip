# AI 自动剪辑（wmy-auto-clip）

一个在本地免费跑的 AI 视频自动剪辑技能。长的剪成短的，散的拼成整的，全程不联网、不花积分、不用任何付费接口。

## 它能做什么

| 模式 | 输入 | 干什么 | 产出 |
|---|---|---|---|
| ① 长剪短 | 一个视频文件 | 转写文字稿 → 剪掉静音空白 → 可选烧字幕 | `X_粗剪.mp4` / `X_粗剪_字幕.mp4` / `X.srt` |
| ② 散拼长 | 素材文件夹 / .zip | 统一分辨率帧率音量 → 按文件名顺序拼合辑 → 可选转场/BGM | `X_合辑.mp4` / `X_剪辑报告.md` |
| ③ 选段拼片 | 素材文件夹 / .zip + 选段单 | 先转写全部素材出文字稿 → 人/AI 挑时间段 → 按挑中的拼 | `X_文字稿.md` / `X_选段合辑.mp4` / `X_选段报告.md` |

动效增强版还能加：呼吸运镜、关键词花字卡、章节卡、进度条、背景音乐闪避。

核心理念：**AI 负责听、剪、拼、拉齐、写这些重复体力活，人当导演**——定顺序、挑片段、改错字。模式③就是"挑片段"的落地：AI 把每段素材转写成带时间戳的文字稿给你看，你（或 WorkBuddy / 豆包）挑，它执行。

## 环境要求

- Windows（脚本与路径约定面向 Windows）
- Python 3.10 及以上
- 本机已安装 `ffmpeg`，且 `ffmpeg` 命令可在终端直接调用
- 转写用本地 faster-whisper，模型本机有就秒开，没有会走国内镜像免费下载（首次需联网）

## 安装

**方式一：手动放（推荐给学员）**

把整个 `wmy-auto-clip` 文件夹复制到 WorkBuddy 的技能目录：

```
C:\Users\<你的用户名>\.workbuddy\skills\wmy-auto-clip\
```

**方式二：用安装器（学员不用碰终端，由 AI 帮你跑）**

```bash
python install.py --zip "<技能包zip路径>"
```

安装器会做四件事并打印结果：核对目录、放好脚本与资源、写入技能元数据、跑一遍自检（22 项体检）。装完记得让它先"体检"一次确认全绿。

## 怎么用

在 WorkBuddy 里直接说人话就行，例如：

- "帮我把这段口播剪到 30 秒，加字幕和配乐"
- "这文件夹里是一堆素材，拼成一条 30 秒宣传片"
- "把这几段里讲得好的挑出来，按顺序拼成合辑"

AI 会调用本技能，按上面的三种模式处理。成片前请过一眼字幕稿 `.srt`——ASR 必有同音错字，要人工校对。

## 目录结构

```
wmy-auto-clip/
├── SKILL.md                 # 技能说明与工作流程（AI 读这个）
├── SPEC.md                  # 技术规格与附加路线
├── install.py               # 安装器 + 自检
├── scripts/
│   ├── autoclip.py          # 主流程：转写 / 剪短 / 拼合辑 / 选段
│   ├── enhance.py           # 动效增强：运镜、花字卡、章节卡、进度条
│   ├── effects.py           # 动效库配置加载
│   └── fx_engine.py         # 动效渲染引擎
├── assets/                  # 背景音乐（首次安装自动从 GitHub Release 下载，见下方说明）
│   ├── bgm.mp3              # 安装时自动下载（Mixkit《Relaxation 05》笛+竖琴）
│   ├── bgm_calm.mp3         # 安装时自动下载（Mixkit《Classical vibes 3》，商用免署名）
│   └── bgm_synth.mp3        # 安装时自动下载（对外正式播出用）
└── references/              # 给学员和讲师的配套文档
    ├── 课程SOP与学员手册.md
    ├── 动效库配置说明.md
    ├── 降噪链调参.md
    └── effects.example.json
```

## 背景音乐授权说明（重要）

- `bgm_calm.mp3` 来自 Mixkit（Classical vibes），商用免署名，但**不得用于电视 / 广播 / CD 发行**。
- 对外正式播出的片子，请改用 `bgm_synth.mp3`。
- 自行替换 `assets/` 里的音乐时，请确认你拥有相应授权。
